## عن التطبيق

**UniBite** تطبيق موبايل لطلب الطعام داخل الحرم الجامعي، يعمل على Android وiOS وWeb.

## التقنيات

| التقنية | الغرض |
|---------|-------|
| Flutter | تطوير متعدد المنصات |
| Dart | لغة البرمجة |
| Firebase | قاعدة البيانات والمصادقة |

## المنصات المدعومة

- 📱 Android
- 🍎 iOS
- 🌐 Web
- 🖥️ Desktop (Linux, macOS, Windows)
